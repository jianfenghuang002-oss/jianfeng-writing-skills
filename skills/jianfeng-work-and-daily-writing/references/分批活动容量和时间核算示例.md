# 分批活动容量和时间核算示例

V12 合成案例，用于演示核算方法。实际项目需按现场口径、岗位、动线和审批状态重新核算。

**口径说明：** 原输入未说明场地总容量40人、活动区20人、候场区20人是否包含工作人员。下表按保守口径，假定三项容量均包含工作人员；该口径仍待场地管理方确认。

## 一、固定参数

| 参数 | 数值 | 说明 |
|---|---:|---|
| 场地总容量 | 40人 | 暂按包含工作人员核算 |
| 活动区容量 | 20人 | 暂按包含工作人员核算 |
| 候场区容量 | 20人 | 暂按包含工作人员核算 |
| 工作人员总数 | 5人 | 全程计入总人数 |
| 活动区工作人员 | 3人 | 两名演示指导员＋一名安全负责人 |
| 候场区工作人员 | 2人 | 现场协调员＋签到/候场人员 |
| 每批活动时长 | 45分钟 | 安全说明10＋演示25＋问答10 |
| 每批结束后轮转 | 10分钟 | 清场、设备复位、人员轮换；每批均计 |
| 开始前签到 | 10分钟 | 单独计时 |
| 全场结束后收尾 | 10分钟 | 与最后一批复位分开计时 |
| 学生批次 | 17、17、17、9人 | 共60人 |

## 二、分区容量计算

| 区域 | 容量上限 | 工作人员 | 学生容量 | 计算 |
|---|---:|---:|---:|---|
| 活动区 | 20 | 3 | 17 | 20－3＝17 |
| 候场区 | 20 | 2 | 18 | 20－2＝18 |
| 全场 | 40 | 5 | 35 | 40－5＝35 |

在组织方确认允许调整原20人组规模后，按活动区学生上限17人控制每批。峰值时一批17人在活动区、下一批17人在候场区，另有5名工作人员：17＋17＋5＝39人，不超过40人。活动区20/20，候场区19/20。

## 四、时间总量核算

| 项目 | 计算 | 分钟 |
|---|---:|---:|
| 开始前签到 | 固定 | 10 |
| 四批活动 | 4×45 | 180 |
| 每批结束后轮转/复位 | 4×10 | 40 |
| 全场最终清点收尾 | 固定 | 10 |
| **合计** | **10＋180＋40＋10** | **240** |
| 开始时间 |  | 14:00 |
| 结束时间 | 14:00＋240分钟 | 18:00 |
| 超出原批准时段 | 18:00－16:00 | 120分钟 |

## 五、修正此前三批方案的时间错误

若仍按三批、每批20人计算，且每批结束后的10分钟复位与最终收尾分开：

10分钟签到＋3×45分钟活动＋3×10分钟复位＋10分钟最终收尾＝185分钟，即14:00—17:05。

此前175分钟的计算只计了两次组间复位，未单列第三批结束后的复位；除非明确确认最后一批复位与最终收尾可并行，否则不得使用175分钟作为完整总时长。

## 六、待确认清单

- [ ] 场地总容量40人是否包含工作人员。
- [ ] 活动区20人是否包含工作人员。
- [ ] 候场区20人是否包含工作人员。
- [ ] 演示站点10人是否包含站点指导员。
- [ ] 原定每组20人能否调整为17、17、17、9人四批；若不能，当前保守容量口径下不可执行。
- [ ] 10分钟内完成第一、二批共34人的签到核验是否可行。
- [ ] 活动区、候场区的出入口是否独立；若共用，如何错峰离场与进场。
- [ ] 现场协调员与签到/候场人员是否可按候场区2人站位履职；若协调员进入活动区，须将其计入活动区并重算每批人数。
- [ ] 是否批准2026年12月10日14:00—18:00使用场地。
- [ ] 10分钟人员轮换的具体岗位交接安排。

**原时段结论：** 按容量包含工作人员、每批最多17名学生、每批复位10分钟与最终收尾10分钟分别计时，14:00—16:00的120分钟只能安排一批17人；两批需要130分钟（10签到＋90活动＋20复位＋10收尾），与原输入提出的“两组活动”存在时间冲突。若组织方确认最后一批复位可与最终收尾并行，两批可在120分钟内完成，但该重叠未获输入支持，不能作为默认方案。
