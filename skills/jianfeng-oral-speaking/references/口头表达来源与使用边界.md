# 口头表达来源与使用边界

## 原版写作 Skill 中保留的 P01 规则

本专项沿用通用写作 Skill 的 P01「演讲、经验分享与口头学术报告」及「演讲与PPT」章节。核心原意如下：

- 经验分享简短建立联系，尽早点明回应的问题；经历、判断和建议之间要形成关系。自我介绍紧邻身份信息，不为每项履历附加感悟。
- 按听众只能顺序听的方式安排背景。上一部分的实际问题、结果或共同关切引出下一部分；建议给出适用理由和开始方式。保留适量称呼、追问、重复与停顿，不把稿件压成标题串。
- 学术口头报告先讲研究问题及其意义，再解释必要概念、展示关键证据、说明结论与范围。图表先提示看哪个对象和比较，再讲发现，不逐项读表。
- 顺PPT逐页核对信息、页序和发言人；履历页完成介绍，案例页展开经历，方法页说明做法。页面之间用内容联系，不重复播报章节名。结尾归拢正文已形成的认识或感受，不追加新口号。

## 证据使用边界

1. 历史试写均为合成情境，不能写成剑锋本人经历、真实组织决定或真实研究成果。
2. 作者试写、作者自审、程序字段检查、独立语义审核、真实听众首听、实际朗读计时是不同证据等级，不能混写。
3. 书籍页码是已有核读记录，不代表全书研读；网页入口不是本轮已重新查证的实时事实来源。
4. 本包最终验证仍是作者内部起草和复核，不是隔离盲审、真人测试或真实系统运行。
