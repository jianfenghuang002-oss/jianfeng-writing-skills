# 事实核对与条件变化规则

## 1. 六类高风险事实

每份稿件都要逐句核对以下维度，重点不是机械查词，而是确认每个事实是否有输入依据：

1. **时间**：最近、上学期、去年、持续半年等均是事实。输入没有时间，不为叙事添时间；不得把当前形成的认识倒写成早期动机。
2. **数量**：确认对象、样本/总体、人次/去重人数、统计期、分母、单位和归属。没有基线或分母，不计算增长率、转化率或提升率。
3. **完成状态**：草稿、已提交、已接收、已采用、已执行、已上线、已验证效果是不同状态。
4. **交接动作**：“交给组员”“提交老师”“客户采用”必须有材料支持。整理文件不等于他人已经接收、阅读或执行。
5. **合作对象**：老师、主管、馆员、管理部门、技术团队、企业客户等身份与角色不得互换。
6. **个人贡献**：本人核对、团队讨论、团队实施、主管决定和审批方认定分开表达。结果发生在同一项目中，不自动归因于个人。

同时核对身份、资格、授权、审批权限、材料来源和因果关系。

## 2. 简历的三轨判断

| 轨道 | 判断内容 | 不得混淆 |
|---|---|---|
| 候选人客观资格 | JD硬条件逐项判符合/不符合/无法判断 | 不满足硬条件不是自动写作失败 |
| 正文质量 | 忠实、相关、清楚、可扫读、本人贡献准确 | 不能把编辑备注、团队结果或不相关经历塞进正文 |
| 缺口处理 | 如实呈现或说明缺口，保持目标岗位不变 | 不能虚构满足、隐瞒条件或偷偷改投泛相关岗位 |

硬条件发生变化时，重新判定资格；不改变候选人的事实。优先条件不得擅自升级为硬条件，硬条件也不得擅自降级。

## 3. 求职打招呼的交流阶段

先识别当前关系，再决定请求：
- **首次联系**：说明身份、具体岗位、最相关的一条证据，提出对方能直接回应的请求。
- **对方已要求补材料**：按要求提供材料，不重复询问是否允许补发。
- **校友/从业者咨询**：提出具体职业问题，不套用向 HR 投递的消息。
- **招聘信息不完整**：只询问影响判断的必要信息，不臆测职位职责或硬条件。
- **岗位关闭或硬条件明确不符**：停止继续申请或如实处理，不假装仍在招聘。
- **已收到追问**：承接对方当前问题，不重发首次联系模板。

## 4. 体裁差异与事实关系

- **简历**：动作和交付优先；不写审稿意见，不以“高度匹配”替代证据。
- **求职信**：解释为什么申请该岗位、哪段经历支撑申请理由；不是拉长的打招呼或简历复述。
- **求职打招呼**：短而可回复，跟随实际交流阶段。
- **自我介绍**：身份、目标和代表经历形成口头叙述；不逐条朗读简历，不给每段追加岗位自评，不以“我可以在面试中讲讲”作为结尾。
- **个人陈述**：经历支撑当前兴趣和申请选择；不写没有依据的“从小热爱”，不把当前认识倒写成过去动机。
- **面试项目陈述**：讲清问题、本人承担、判断及依据、操作、团队分工、结果和边界；结果不足时说可核交付。
- **人物简介**：介绍人物是谁和有依据的代表经历，不扩成长名单。
- **事迹材料**：用具体事件和行动支撑评价，不把人物简介扩写成奖项清单。
- **推荐材料**：推荐人的观察关系限制评价范围；本人自述不能伪装成推荐人亲见。
- **普通申请**：明确申请事项、依据、所需决定和必要附件；不夸大紧迫性。
- **请示**：组织关系内向有权限的上级提出需批准/指示的事项；学校内部文书按本单位制度，不自动套用党政机关正式公文规则。
- **情况说明**：说明事件、时间线、已知事实、处理状态和待确认事项；不替当事人编动机，不把“页面未显示”推断为“系统未保存”。
- **评优材料**：先核对当年资格与评审维度，再组织证明；不把国家奖学金和校内自设荣誉混成一套规则。

## 5. 条件变化与版本记录

条件变化必须说明：
- 版本标签（如 CF-v0、CF-v1）；
- 原始条件与后续细化条件分别是什么；
- 是否真正改变基线事实或证据状态；
- 哪个数字、行动、结论、请求或资格因此失效；
- 当前采用的完整重写稿；
- 历史首次变化稿是否实际保存。

若原条件与基线重复，应标为无效/重复条件，不与后续有效变化混称。历史首次稿没有保存时明确注明，不得将较早修订稿冒充首次稿。
